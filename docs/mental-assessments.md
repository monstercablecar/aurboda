# Mental assessments

The `/assessments` page is a library of external tests with manual result entry. It distinguishes established self-report instruments, an informal IQ-style reasoning estimate, quick performance benchmarks, and rotating research studies. It does not administer clinical assessments or diagnose conditions.

## Selection and sources

Links and scoring documentation checked November 11, 2026. All selected options offer free testing/results at the time of review. No external provider promises permanent availability. Prefer the institutional or library landing page over an ephemeral study/session URL.

The academic PsyToolkit pages link to runnable demos and publish scoring code. Using their stable explanatory pages also makes the instrument identity recoverable if a demo URL changes. IPIP's public-domain materials and the Big Five host's open source make that instrument more recoverable than a proprietary online-only quiz. The underlying copyrighted tests are not copied into Aurboda.

## Recording and comparison

Use the same provider, instrument version, score convention, and (for performance tests) device and input method across comparisons. Save the actual test time and optional conditions such as fatigue, distractions, first/repeat attempt, and number of trials. The server separately records when the entry was created. Retakes are allowed at any time, including more than once per day. Overlapping recall windows and practice effects limit what changes mean.

Results use Aurboda's authenticated questionnaire/assessment API and PostgreSQL storage, with immutable question versions and a saved provenance snapshot. Numeric instrument-specific fields can appear in Aurboda's existing chart/analysis features. No external account or result scraping is required. External tests retain their own privacy and research-consent policies.

The export preserves stored results independently of external report URLs. For longevity, copy the relevant report details into notes rather than relying only on a share link. The catalog should be versioned when providers change scoring or test protocols; do not silently reuse a metric for a different scale.

## Verification

The page was built and deployed to the private Foghouse installation on November 11, 2026, using the existing backup/build/restart workflow. Focused assessment/navigation tests (14), TypeScript checks, and changed-file lint passed. Existing assessment backend service/router tests (15) passed with Node 26. The broader web suite passed 1,467 tests with two initial failures: the timezone subprocess test passed when rerun with process access; an unrelated existing Celebration.css viewport-unit test remains failing. Android SDK was unavailable, so the Android menu addition was not built or tested. No sample assessment scores were inserted into the user's account.

Browser checks covered authenticated loading, category filtering, required-score validation, and narrow/desktop layout. A desktop padding overflow found during visual review was corrected before the final release.

The Big Five scoring format selector supports IPIP-NEO-120 raw domain totals of 24–120 and IPIP-NEO-300 raw domain totals of 60–300. Select the format used by the original test report before entering scores. Each format keeps its own questionnaire, metrics, history, and recorded provenance; existing IPIP-NEO-120 questionnaires and results remain unchanged. No database edits or score conversions are needed.

The Mensa result format selector also accepts the exact descriptive message when the provider returns no numeric estimate. This uses a separate questionnaire without numeric metrics; it never fabricates an IQ score or changes existing numeric results. The provider describes the out-of-range message at https://www.mensa.org/mensa-iq-challenge/ .
